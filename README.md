## Overview

This repository contains the complete, reproducible research package accompanying the manuscript:

> **From Waste to Fertile Land: Complementary Circular Bioeconomy Pathways Based on Silicate Rock Dust for the Recovery of Degraded Soils in Atlántico, Colombia**

The study develops a multivariate decision framework (Principal Component Analysis + K-means clustering + multiple linear regression) based on X-ray diffraction (XRD) mineral phase data. The framework classifies silicate rock dusts according to their agronomic potential as soil remineralizers and supports circular bioeconomy pathways aimed at restoring degraded lands in the department of Atlántico, Colombia.

### Key Results

| Analysis              | Main Finding                                                                 |
|-----------------------|-----------------------------------------------------------------------------|
| PCA                   | First two components explain **54.4 %** of total variance                   |
| K-means (k = 3)       | Clear separation into **Premium / Standard / Discard** classes              |
| Multiple Regression   | Particle size (mesh) is the dominant predictor of relative solubility (**Adjusted R² = 0.982**) |
| Decision Rule         | Only Premium-class materials with mesh ≥ 200 are recommended for agricultural use |
